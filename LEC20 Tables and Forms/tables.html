HTML Table Attributes Summary

📘 HTML Table Attributes Summary

Attribute Used In Purpose / Controls Example
border <table> Adds a border around the table and its cells <table border="1">
cellspacing <table> Controls space between cells <table cellspacing="0">
cellpadding <table> Controls space inside each cell (padding) <table cellpadding="5">
width <table>, <td>, <th> Sets width of table or individual column/cell <td width="50%">
height <td>, <th> Sets height of a specific cell <td height="100">
bgcolor <table>, <tr>, <td>, <th> Sets background color <td bgcolor="lightblue">
align <table>, <td>, <th> Horizontal alignment of table or text <td align="center">
valign <td>, <th> Vertical alignment of content within a cell <td valign="top">
colspan <td>, <th> Merges multiple columns into one cell <td colspan="2">
rowspan <td>, <th> Merges multiple rows into one cell <td rowspan="3">
bordercolor <table> Changes border color (old HTML only) <table bordercolor="blue">

Note: These are legacy HTML attributes. In modern HTML5, use CSS instead for styling.
